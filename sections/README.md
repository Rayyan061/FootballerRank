# FootballerRank homepage sections

Each `.html` file is intended for its own WordPress Custom HTML block on the `Home` page. Keep sections separate so they can be reordered, duplicated, disabled, or edited independently.

Shared presentation lives in `assets/css/footballerrank.css`; shared interaction logic lives in `assets/js/footballerrank.js`. Do not paste duplicate `<style>` or `<script>` tags into page blocks.

Initial build order:

1. `hero.html`
2. Top Players query section
3. Browse by Position
4. All-Time Greats
5. Player Comparisons query section
6. Records & Achievements
7. Featured Player Profiles query section
8. Research query section
9. Trust / methodology
